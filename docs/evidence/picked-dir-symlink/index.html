Does a handle walk follow a symlink?

What this page does and does not do. It reads only what you pick. It makes no network calls and sends nothing anywhere. The optional write probe creates one file through the link and removes it — off by default, because a write probe that always ran would change the folder it is measuring.

What it measures, precisely (the first version of this instrument measured less than it claimed — a reviewer was right to say so): a directory symlink, a file symlink, and — if you enable it — the write path. It does not establish anything about other handle operations, and each probe says so in its own line rather than being rounded into one verdict.

  1. In a terminal: 
    mkdir -p /tmp/vb-symlink-probe/inside && cd /tmp/vb-symlink-probe
ln -s /etc outside-dir          # a DIRECTORY symlink pointing out
ln -s /etc/hostname outside-file # a FILE symlink pointing out
echo secret > inside/real.txt
  2. Click Pick that folder and choose /tmp/vb-symlink-probe.
  3. Paste the result into RECEIPT.md. Nothing is uploaded anywhere.
