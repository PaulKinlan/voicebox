Voicebox — Help & User Guide

Complete reference for live voice conversation, camera and screen vision, extended thinking models, workspace files, interactive mini-apps, and coding harnesses.

← Back to Voicebox

1. Getting Started & Live Voice Conversation

Voicebox is a spoken and visual interface to a real project folder on your computer or in your browser. Every action is grounded in your declared project root.

  • Starting & Stopping the Microphone: Click the centered Microphone button (or press M on your keyboard) to connect and start speaking. Press M again to disconnect and mute the microphone.
  • Natural Barge-In & Interruption: You can speak at any time while the assistant is talking to interrupt and redirect it, or click Stop reply to silence audio playback while keeping the microphone active.
  • Text Turn Composer: When your microphone is off or you prefer typing, use the text input directly below the microphone to send any question or file command.
  • Docked Microphone: When you scroll or open panels, a floating microphone button stays accessible in the bottom-right corner so you can toggle voice from anywhere.

2. Live Vision: Camera & Desktop Screen Sharing

Give the voice assistant live visual context using the camera and screen controls right beside the microphone:

  • Camera Streaming: Click Camera to stream frames from your webcam into the active live session so the assistant can see physical objects, sketches, or devices.
  • Screen & Window Sharing: Click Share screen to share a browser tab, application window, or entire display so the assistant can inspect layouts, errors, or documents with you.
  • Instant Frame & Manual Speech Boundaries: Use Send frame inside the video preview card to capture an immediate frame, Stop video to stop sharing at any time, or enable Push to talk in Settings if you want manual speech start and end controls beside the microphone.
  • Vision Settings: Open Settings in the top bar to adjust Video frame resolution (Low for fastest turn response, Medium for balanced detail, High for fine text and UI detail) and Video frame rate (0.5, 1, or 2 frames per second).

3. Models, Extended Thinking & Provider API Keys

Open Settings in the top bar to choose your voice provider, model, reasoning depth, and voice persona:

  • Gemini 3.8 Live (Default): Tuned for low-latency, real-time spoken conversation and immediate tool calls.
  • Gemini 3.8 Live Extended Thinking: Combines live spoken interaction with deep multi-step reasoning and non-blocking background tool execution. Configure Extended thinking depth (Low, Medium, or High) under Agent Settings for both live audio and video sessions.
  • Automatic Session Restart on Model Change: When you switch models, thinking depth, or providers (Gemini Live, OpenAI Realtime, or Claude) in Settings while a live voice session is running, Voicebox automatically disconnects the previous session and reconnects using your new selection.
  • Provider API Keys: Enter and save your Gemini, OpenAI, and Anthropic API keys directly in Settings so they persist on your local host without needing shell environment variables.
  • Voice Timbre & Persona: Choose from Balanced, Warm, Bright, Deep, or Crisp voice timbres and layer a persona or custom prompt guidance beneath the mandatory safety rules.

4. Workspace Files, File Viewer & Interactive Mini-Apps

Browse, read, edit, and run files from your active project folder:

  • Files Bubble & Explorer: Click the Files bubble in the Home deck (or bottom dock) to open the project file list, navigate into subfolders, filter files by name, create a new file, or open a local folder from your computer.
  • File Viewer & In-Place Editor: Click any file card (or say "open notes.md") to inspect its contents in the floating File Viewer. Click Edit to modify and save text directly, Copy to copy to your clipboard, or Download to save a copy.
  • Interactive Mini-Apps: HTML applications in your workspace can be launched as live interactive Mini-Apps right inside the room. Use the Mini-App header bar to expand full-screen, reload, edit source, or minimize the app into the bottom-right bubble dock.

5. Coding Harnesses, Environments & Extensions

Delegate complex engineering work and manage where your files live using the top-right header controls:

  • Harnesses (External Coding Agents): Open Harnesses to check and connect installed coding agents on your machine (Pi, Claude Code, Antigravity, Codex, OpenCode). Multiple harnesses can be active simultaneously, and delegated tasks report live progress in the Activity panel.
  • Environments: Open Environments to switch between your browser workspace, your local machine folder, or a remote Voicebox server connection.
  • Extensions: Open Extensions to inspect running tools, review waiting proposals, reconfigure network limits, or create a new local extension tool.
  • Change Log & Sync Notice: Open Change log in the top bar to review recent commits. If the browser UI and server ever drift out of sync after an update, a top banner offers a one-click Reload page action.

6. Voice Commands & Keyboard Shortcuts Reference

Keyboard Shortcuts

  • M — Start or stop the live microphone (customizable in Settings)
  • ? — Open or close the in-room Help & User Guide
  • Escape — Close the active popover, file viewer, or modal dialog
  • Enter — Submit a typed turn from the text composer

Spoken & Typed Commands

  • "Open files" / "Close files" — Toggle the Files explorer popover
  • "Show history" / "Show activity" — Open turn history or agent activity log
  • "Open settings" — Open the Settings dialog
  • "Switch to dark theme" / "Switch to light theme" — Change room appearance
  • "Open <filename>" — Open a project file in the File Viewer
  • "Create a file called <name>" — Create a new file in the active folder
  • "Undo last change" — Revert the most recent local folder edit

7. Troubleshooting & Common Questions

  • Microphone is unavailable or permission denied: Check your browser address bar permissions for microphone access, or select a specific input device under Settings → Microphone. You can always use the text composer below the microphone while audio is off.
  • Live voice says a model is unavailable: Open Settings → Model and select Gemini 3.8 Live (default) or Gemini 3.8 Live Extended Thinking, and verify your provider API key is configured under Provider API Keys.
  • Folder access needs to be restored after reload: When using a browser-picked local directory, click Restore access in the folders bar so the browser re-grants read/write permission for the current session.
