Scope and limits

Each harness keeps its own security and configuration; this does not wrap it in a Voicebox sandbox.

A browser cannot start a local CLI by itself. To reach programs on your browser's machine, a local server or helper would need to bridge that connection. This page does not build that bridge. Browser-native harnesses need no such bridge, but are not discovered here.

This is installed-program inventory, not configured agents, a default selection, or fleet/session addressing. Descriptions are known program purposes, not observed permissions. Cost, model access and task readiness are unknown.

The existing Pi task executor still refuses absent-capability because its code requires an absent provider broker. That older restriction has not yet been removed to match independent-harness policy. Inventory does not enable delegation or recommend adding a broker.
