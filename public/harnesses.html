Scope and limits

Each harness keeps its own security and configuration; this does not wrap it in a Voicebox sandbox.

A browser cannot start a local CLI by itself. To reach programs on your browser's machine, a local server or helper would need to bridge that connection. This page does not build that bridge. Browser-native harnesses need no such bridge, but are not discovered here.

This is installed-program inventory with optional host-declared tool metadata, not configured agents, a default selection, or fleet/session addressing. Metadata does not prove active tools or permissions. Cost, model access and task readiness are unknown.

ACP declares protocol capabilities, not a list of agent tools. No MCP servers or private extensions are inspected here. To supply tool names and descriptions, set VOICEBOX_HARNESS_TOOLS on the server to a metadata file. Catalogue format and limits.

Pi coding agent is supported via the pi-acp adapter (start the server with VOICEBOX_HARNESS=pi). Other CLIs (like Claude Code) have no configured ACP adapter and cannot be delegated to directly.
