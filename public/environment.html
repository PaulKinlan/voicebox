voicebox — projects and folders

A project's files live in one of three places: the browser's own storage for this site, a folder you pick, or a folder on this machine. This page always says which one, and says who can change the files there. The same project name in a different browser is a different project — nothing here tries to match them up.

Open a project

Choose a folder on this machine and turns can save into it today. A folder you pick in the browser stays read-only for turns for now — the browser hands that folder to this page and not to the server, so the server cannot save there yet.

Open opens a project kept in this browser's own storage (origin storage, OPFS) — not a folder on your disk. It makes that project the one this page acts on, creating it empty if the name is new.

The path is a folder on this machine — type or paste its absolute path. The server (which runs turns) writes there, so this is the choice that lets turns save files you can open in your own editor.

How this page talks to those environments

The browser environment is a worker inside this page — it answers over a message channel, no network. The local server is an HTTP API on this machine (loopback): the page asks, the server acts inside its own root and answers with what it observed or a named refusal. A remote environment is the same API on another machine, reached through a paired credential — the page never holds the remote's key. The one rule across all three: a decision never crosses the wire — an answer carries observed facts or a named refusal, never a grant.
