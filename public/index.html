            Environments

            An environment is a place your project can live and turns can run: this browser, a server on this machine, or a server on another machine you can reach. The first box is what you will call it in the list; the second is how to reach that machine's server — the same address you would open in a browser, for example http://127.0.0.1:8787. Turns run on a server environment while that server is answering, and a server that is not answering says so when you look.
