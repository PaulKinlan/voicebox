    Voicebox Help & User Guide

    Everything you can do with live voice, camera, screen sharing, workspace files, mini-apps, and coding agents.

    1. Getting Started & Voice Conversation

    Press the centered Microphone button (or press M on your keyboard) to start or stop a live two-way voice conversation with Voicebox.

    • Natural Barge-In: Speak at any time while the assistant is talking to interrupt and redirect the conversation, or click Stop reply to silence audio playback while keeping the microphone open.
    • Text Turn Composer: Prefer typing or working in a quiet space? Use the text input below the microphone to send any question or file command directly.

    2. Live Vision: Camera & Desktop Screen Sharing

    Share visual context with your live voice session using the controls right beside the microphone:

    • Camera & Share screen: Click Camera to stream from your webcam or Share screen to share a window or display so the assistant can see what you are working on.
    • Snapshots & Activity Boundaries: Click Send frame to transmit an immediate still frame, use Push to talk to signal manual speech start and end boundaries, or click Stop video to end video capture.
    • Resolution & Frame Rate: Open Settings to choose Low, Medium, or High video frame resolution and 0.5, 1, or 2 frames per second.

    3. Models, Extended Thinking & API Keys

    Open Settings in the top bar to configure your voice model, reasoning depth, and provider credentials:

    • Gemini 3.8 Live: Optimized for the fastest conversational turn response and lowest audio latency.
    • Gemini 3.8 Live Extended Thinking: Enables deep multi-step reasoning with configurable thinking depth (Low, Medium, or High) and non-blocking background tool execution.
    • Automatic Reconnect on Model Change: Switching your model or provider (Gemini Live, OpenAI Realtime, or Claude) while a live voice session is active automatically disconnects and restarts the session with the new selection.
    • API Keys & Voice Persona: Save your Gemini, OpenAI, and Anthropic keys on the host and customize voice timbre and assistant persona.

    4. Workspace Files, File Viewer & Interactive Mini-Apps

    Everything you create or inspect lives in your active project folder:

    • Files Popover: Click the Files bubble in the Home deck (or bottom dock) to browse directories, filter files by name, create a new file, or open a folder from your computer.
    • File Viewer & In-Place Editor: Click any file (or say "open notes.md") to view its contents, edit and save changes in place, copy text, or download the file.
    • Interactive Mini-Apps: Any HTML application in your workspace can be launched as an interactive Mini-App right inside the room, with controls to expand, reload, edit, or minimize into the bottom-right bubble dock.

    5. Coding Harnesses, Paired Environments & Extensions

    Connect external coding agents, switch workspaces, and expand assistant tools from the top bar:

    • Harnesses: Connect installed coding agents (Pi, Claude Code, Antigravity, Codex, OpenCode) to delegate complex multi-file engineering tasks by voice or text and track progress live.
    • Environments: Switch between your browser workspace, a local folder on your computer, or a remote server connection.
    • Extensions: Inspect running tools, review waiting proposals, or create custom local tool definitions for the assistant.

    6. Voice Commands & Keyboard Shortcuts Reference

    Keyboard Shortcuts

    • M — Start or stop the live microphone
    • ? — Open or close this Help guide
    • Escape — Close the active popover or dialog
    • Enter — Send a typed turn from the text box

    Spoken Commands

    • "Open files" / "Show history" / "Open settings"
    • "Switch to dark theme" / "Switch to light theme"
    • "Open <filename>" / "Create a file called <name>"
    • "Undo last change" / "Search for <text>"

                  Environments

                  Environments are where your project files live and where commands run: this browser, your local machine, or a remote server.

                  What is an environment?

                  An environment defines where your project files live and where tools and coding agents run:

                  • Browser Workspace: Built-in browser storage for quick notes, files, and interactive mini-apps with zero machine setup.
                  • Local Machine Folder: A project folder on your computer where files are read and edited directly on disk.
                  • Remote Server Connection: Another machine running Voicebox on your local network or private tailnet.

                  How to add & connect an environment

                  1. Start the Voicebox server on the target machine (for example http://127.0.0.1:8787 or a network host URL).
                  2. Enter a friendly Name (such as atlas box) and the server Origin URL under Add an environment below, then click Add environment.
                  3. Click Pair on the added row to authorize the connection, then click Use to switch your active workspace to that environment.
